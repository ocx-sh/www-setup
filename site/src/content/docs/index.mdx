Install `ocx` on Linux, macOS or Windows with one command in the shell you already use.
No root access is needed.
Pick your shell and paste the command.

## Install in your shell {#install}

<Tabs syncKey="shell">
  <TabItem label="Shell" icon="shell">

```sh
curl -fsSL https://setup.ocx.sh/sh | sh
```

Works in bash, zsh, dash, ash and ksh on Linux and macOS.
It needs `curl` or `wget`, and one of `sha256sum`, `shasum` or `openssl`.

  </TabItem>
  <TabItem label="PowerShell" icon="powershell">

```powershell
irm https://setup.ocx.sh/pwsh | iex
```

Works in Windows PowerShell 5.1 and PowerShell 7 on Windows, and in PowerShell 7 on Linux and macOS.
On Linux and macOS it also needs `tar`.

  </TabItem>
  <TabItem label="Nushell" icon="nushell">

From a POSIX shell:

```sh
nu -c "$(curl -fsSL https://setup.ocx.sh/nu || echo 'exit 3')"
```

From inside Nushell:

```nu
nu -c (http get https://setup.ocx.sh/nu)
```

Needs Nushell 0.105.1 or later. It works on Linux, macOS and Windows.
A bare `curl https://setup.ocx.sh/nu | nu` installs nothing, because Nushell does not run a script from a pipe.

  </TabItem>
  <TabItem label="fish" icon="fish">

```fish
curl -fsSL https://setup.ocx.sh/fish | fish
```

Needs fish 3.6.0 or later on Linux or macOS. It does not run on Windows.

  </TabItem>
  <TabItem label="Elvish" icon="elvish">

From a POSIX shell:

```sh
elvish -c "$(curl -fsSL https://setup.ocx.sh/elvish || echo 'exit 3')"
```

From inside Elvish:

```sh
elvish -c (e:curl -fsSL https://setup.ocx.sh/elvish | slurp)
```

Needs Elvish 0.20.1 or later. It works on Linux, macOS and Windows.
A bare `curl https://setup.ocx.sh/elvish | elvish` installs nothing and exits 0, because Elvish reads the pipe as a terminal session.

  </TabItem>
</Tabs>

The installer prints its progress to stderr and then hands over to `ocx self setup`.
That command installs OCX into your OCX home directory, `~/.ocx` by default, and adds OCX to your shell profile.

The installer checks the archive against the SHA-256 digest in its manifest before it runs anything from the archive.
Open a new terminal and run `ocx about` to confirm that `ocx` is on your path.
[Installer output](/install/examples/dev-box/#output) shows what the installer prints.

## Install in CI {#ci}

In CI, use the maintained integration for your provider.
It installs `ocx` and, in a project with an `ocx.lock`, pulls the pinned toolchain.

<HubGrid hub="integrations" category="ci" />

For any other CI system, see the [generic CI wrapper](/install/examples/#ci-wrapper).
Pin the installer and the version in CI, as [Pin a version](/install/versions/) describes.
